# INNER Telegram Mini App

Рабочая ветка: `feature/telegram-mini-app`.

## Первый релиз

- mobile-first главная страница;
- premium dark ice дизайн;
- каталог с поиском;
- категории;
- избранное;
- нижняя навигация;
- iPhone safe area;
- адаптация для широких экранов;
- автоматическая проверка сборки через GitHub Actions.

## Следующие этапы

1. Подключить настоящую базу товаров.
2. Сделать маршруты каталога и карточки товара.
3. Добавить корзину и оформление заявки.
4. Подключить Telegram WebApp SDK.
5. Добавить админку товаров, заказов и заявок.
6. Подключить хранение изображений и уведомления Telegram.
